# Smart Energy Meter with GSM Billing

## Overview
This project is a Smart Energy Meter system developed using Arduino and GSM technology. 
The system measures electricity consumption and sends billing information through SMS.

## Features
- Real-time energy monitoring
- GSM-based bill notification
- LCD display output
- Low-cost implementation
- Easy to install

## Components Used
- Arduino Uno
- ACS712 Current Sensor
- SIM800L GSM Module
- 16x2 LCD Display
- Breadboard
- Jumper Wires

## Software Used
- Arduino IDE
- Proteus (Optional)

## Working Principle
1. Current sensor measures current consumption.
2. Arduino calculates power usage.
3. LCD displays live readings.
4. GSM module sends SMS bill notification.


## Applications
- Smart homes
- Electricity monitoring
- Industrial energy management

## Future Scope
- Mobile app integration
- IoT cloud monitoring
- Online billing system
